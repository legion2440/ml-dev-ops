# Sample images

This directory contains ten real, small public-domain or CC0 photographs covering
animals, vehicles, and common objects. `manifest.json` records the source page,
license, attribution, SHA-256, and decoded dimensions for every image.

`scripts/validate_client.py` rejects missing, untracked, duplicate, oversized,
undecodable, or stale samples. Additions must retain HTTPS provenance and a
public-domain-compatible license record.
