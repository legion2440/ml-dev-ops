# Triton model repository

This directory contains the canonical model specification, generated manifest, three explicit Triton configs, and model-local label files.

The local serving binaries are generated by `make prepare-models` and ignored by Git:

- `resnet50_onnx/1/model.onnx`;
- `resnet50_tensorrt/1/model_cc89.plan`;
- `yolo11n_onnx/1/model.onnx`.

Do not add top-level cache, downloads, or labels directories here: Triton interprets top-level directories as model candidates. Preparation cache belongs under `.cache/model-preparation`.

Run `python scripts/validate_model_repository.py --structure-only` on a clean checkout or the full validator when local binaries exist.
